# Medical Appointment Data Preprocessing

## Overview
This project preprocesses the Medical Appointment No-Show dataset using Python and Pandas.

## Tasks Performed
- Dataset loading
- Data exploration
- Missing value handling
- Duplicate removal
- Date conversion
- Encoding categorical variables
- Statistical analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Google Colab

## Output
Cleaned dataset ready for analysis and machine learning.
